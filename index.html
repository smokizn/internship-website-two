Program details

Twelve weeks, four clear phases.

  1. Weeks 1–2

    Orientation & setup

    Tooling, workflows and a first small task merged into a shared repository.

  2. Weeks 3–6

    Guided labs

    Weekly hands-on labs with mentor code reviews and written feedback.

  3. Weeks 7–10

    Capstone build

    Plan and build an independent project with checkpoints every week.

  4. Weeks 11–12

    Demo & review

    Present your work, document it and receive a final assessment.

FAQ

Questions, answered.

Do I need prior experience?

No. Beginner-friendly tracks start from the fundamentals. Intermediate and advanced tracks list their prerequisites on the application form.

Can I study while working part time?

Yes. The program is designed around roughly 20 hours per week, and most lessons are available online.

What do I need to bring?

A laptop that can run a modern browser and a terminal. Lab environments are provided for heavier workloads.
